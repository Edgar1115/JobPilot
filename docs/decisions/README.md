# decisions — 架构决策记录（ADR）

记录重要架构决策与取舍（规格书 v2.0 第 6 章 docs/decisions）。

## 建议格式

```markdown
# ADR-{序号}: {标题}

## 状态
Proposed / Accepted / Deprecated

## 背景
- 问题是什么
- 为什么需要决策

## 决策
选择了什么方案

## 被否决的替代方案
- 方案 A：为什么否决
- 方案 B：为什么否决

## 影响
- 好处
- 代价 / 风险
```
