# sources — 学习来源记录

记录从教学视频、GitHub / Gitee 项目、技术文章、工作实践中学到的模块来源（规格书 v2.0 第 6.7 节）。

## 吸收流程

```text
1. 记录来源
2. 写清它解决的问题
3. 提取核心机制
4. 在 Lab 最小复现
5. 主动制造边界 / 异常场景
6. 写实验结论
7. 判断是否值得成为 Reference
8. 如果 Core 确实需要，再做正式集成
```

## 条目模板

```markdown
## {技术名称}

- 来源：{URL / 视频 / 项目}
- 许可证：{如适用}
- 想解决的问题：{一句话}
- 核心机制：{要点}
- 对应 Lab：{路径}
- 日期：{yyyy-mm-dd}
```

禁止整段复制外部项目代码作为依赖；引用源码时记录来源与许可证（规格书强制规则 19）。
